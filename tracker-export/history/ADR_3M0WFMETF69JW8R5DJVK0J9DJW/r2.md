## Status

Accepted

## Context

GraphScript represents project runtime functions, classes, and shared state as graph nodes. The library build also supported relative local helper files, which required separate dependency discovery and copying. A file URL does not retain whether its source path was relative or absolute.

## Decision

GraphScript source uses the graph alias for project runtime nodes and package imports for external libraries. Relative runtime code imports and file: URL imports in GraphScript source are errors. This rule does not restrict imports inside external packages or imports generated by the compiler. It is not a sandbox.

## Consequences

- GraphScript runtime dependencies do not require a separate local helper-copy policy.
- External package dependencies remain ordinary imports.
- Absolute file URL imports are not permitted in GraphScript source.
- Type-only imports are not decided by this record.
