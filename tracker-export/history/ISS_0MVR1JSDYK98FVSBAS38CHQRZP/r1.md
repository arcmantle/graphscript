## Work Mode

HITL

## Outcome

A maintainer has reviewed the installed explorer and recorded the result against the exact release artifacts.

## Scope

- Perform the required human explorer review using the installed release candidate packages.
- Review source navigation, default focus, depth controls, full graph, direct dependencies, cycles, saved updates, and protected edit behavior.
- Use a representative project that includes function, class, and shared-state nodes and a dense graph.
- Record artifact identities, host and tool versions, observations, and any material defects.

## Acceptance Criteria

- A human reviewer completes and records the explorer review rather than substituting an automated result.
- The record identifies the exact compiler and extension artifacts and the host and VS Code versions.
- The required explorer interactions and representative dense-graph behavior have recorded observations.
- Material failures are reported and prevent an unqualified passing review.
- The record does not claim support for host combinations without required evidence.
