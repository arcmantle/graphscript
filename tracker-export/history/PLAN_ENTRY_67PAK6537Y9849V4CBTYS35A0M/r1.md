Which directive form should GraphScript use to mark node kinds? Example string directives are `"use graphscript:function";`, `"use graphscript:class";`, and `"use graphscript:state";`. Alternatives include a comment such as `// @graphscript-node state`, or a new statement such as `graphscript state;`. Recommended: use the namespaced string directive because it is compact, easy to read, and valid JavaScript syntax without adding a parser keyword.
