How must tools handle managed source-file changes made outside GraphScript commands, including Git changes? Options: detect saved changes automatically and report inconsistencies without rewriting source; or require an explicit refresh or repair command. Recommendation: automatic detection. Rebuild derived graph data from valid saved source, preserve existing node identities, and report missing files, duplicate names, or inconsistent identity data. Do not silently rewrite source or assign a different identity. The identity storage format remains an implementation decision.
