## Compiler versions and publication requirements

Use Node.js 24 and TypeScript 7 for the first release. Do not extend the support guarantee to other major versions.

Before publication, fix and test exact supported version limits, the desktop VS Code range, and the extension-to-compiler compatibility range. Fix npm package identifiers, CLI command names, extension and publisher identifiers, release versions, license, and required package metadata. Verify identifier ownership and artifact installation.

These are required publication checks, not claims of completed validation. Exact values remain publication metadata rather than additional design questions.
